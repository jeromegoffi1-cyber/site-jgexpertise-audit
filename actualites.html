Actu fiscaleOctobre 2026

Facturation électronique : les dates à retenir

Toutes les entreprises doivent pouvoir recevoir des factures électroniques depuis le 1er septembre 2026. Les PME et les micro-entreprises devront les émettre à partir du 1er septembre 2027.

Indépendants : une nouvelle base pour vos cotisations

Depuis la déclaration des revenus 2025, les cotisations sociales des travailleurs indépendants sont calculées sur le revenu brut social. Ce qui change.

Lire l'article →Actu socialeOctobre 2026

Prime carburant : jusqu'à 1 000 € exonérés de cotisations jusqu'à fin 2026

Le plafond d'exonération sociale des aides aux frais de transport est porté à 1 000 € pour les sommes versées jusqu'au 31 décembre 2026. Côté impôt, le relèvement n'est pas encore voté.

Nouveau code APE au 1er janvier 2027 : ce qu'il faut vérifier

Toutes les entreprises changent de code APE au 1er janvier 2027. Le futur code est déjà consultable et peut être corrigé.
