Actu juridique Octobre 2026

Nouveau code APE au 1er janvier 2027 : ce qu'il faut vérifier

Au 1er janvier 2027, toutes les entreprises, associations et administrations changent de code APE avec l'entrée en vigueur de la nouvelle nomenclature d'activités, la NAF 2025. Le futur code est déjà consultable : mieux vaut le vérifier avant la bascule.

Ce qui change

Un décret du 31 juillet 2025 a approuvé une nouvelle nomenclature d'activités française, la NAF 2025, adaptée de la nomenclature européenne. Elle remplace celle de 2008 et devient, au 1er janvier 2027, la référence pour l'attribution du code APE, le code qui identifie l'activité principale exercée.

Toutes les entités actives inscrites au répertoire Sirene, ainsi que leurs établissements, reçoivent un nouveau code à cette date, y compris les micro-entrepreneurs. La bascule se fait automatiquement.

Pourquoi le vérifier

Le code APE est attribué à des fins statistiques et ne crée, à lui seul, ni droit ni obligation. Il est pourtant repris par de nombreux organismes et partenaires, et sert souvent de repère, par exemple pour identifier la convention collective ou l'organisme de formation dont relève l'entreprise. Un code mal attribué peut donc créer des difficultés.

Certaines activités sont découpées autrement qu'avant : un même ancien code peut se répartir entre plusieurs nouveaux codes. Pour les artisans, la liste des activités relevant de l'artisanat a aussi été mise à jour selon la NAF 2025, avec effet au 1er janvier 2027.

Comment faire

Le futur code de chaque entreprise et de chaque établissement est affiché sur sirene.gouv.fr. Si le code proposé ne correspond pas à l'activité réellement exercée, le même site permet d'en demander la rectification.

Mieux vaut faire cette vérification avant la fin de l'année, en même temps que celle des documents qui mentionnent le code APE, comme les bulletins de paie.
